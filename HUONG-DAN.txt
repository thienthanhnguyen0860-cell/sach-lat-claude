CÁCH 1 – GITHUB PAGES (miễn phí, link cố định)
1. Đăng nhập github.com (tạo tài khoản miễn phí nếu chưa có).
2. Bấm "+" góc trên phải -> "New repository". Đặt tên, ví dụ: sach-lat-claude. Chọn Public -> "Create repository".
3. Bấm "uploading an existing file". Kéo thả các file trong thư mục này vào.
   GitHub giới hạn 100 file mỗi lần tải: lần 1 kéo thư mục "p", bấm "Commit changes";
   lần 2 kéo index.html, thư mục js, file PDF, HUONG-DAN.txt, bấm "Commit changes".
4. Vào "Settings" -> "Pages". Mục "Branch" chọn "main", thư mục "/ (root)" -> "Save".
5. Đợi 1–2 phút, link có dạng: https://<ten-tai-khoan>.github.io/sach-lat-claude/
